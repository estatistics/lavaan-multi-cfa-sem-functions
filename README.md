# lavaan-multi-cfa-sem-functions
Automated R functions for lavaan &amp; semPlot that can handle multiple datasets (eg. different experimental treatments, time series) and organize tables from multiple CFAs and SEMS per case, per treatment etc.  Batch CFA/SEM,  Batch Test-Retest Reliability, Batch Multivariate Normality,  Auto-Splitting datasets in subscales, Excluding criteria.
